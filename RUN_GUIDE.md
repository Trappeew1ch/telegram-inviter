# Telegram Inviter Bot: Step-by-Step Guide

This guide will walk you through setting up and running the Telegram Inviter Bot.

## 1. Prerequisites

*   **Python 3.x:** Ensure you have Python version 3.x installed on your system. You can download it from [python.org](https://www.python.org/).
*   **pip:** Python's package installer, `pip`, is required to install dependencies. It usually comes with Python 3.x.

## 2. Installation of Dependencies

The bot relies on several Python libraries. Install them using pip:

```bash
pip install telethon aiogram
```
*(Note: While `pysqlite3` is common for some bots, this particular bot uses a custom JSON-based database (`pickledb`) for its simple needs, so `telethon` and `aiogram` are the primary external libraries.)*

## 3. Configuration

Proper configuration is crucial for the bot to function correctly. All configuration files are located within the project directory.

### 3.1. `settings/config.py` (CRITICAL)

This is the main configuration file for bot behavior and credentials.

*   **`BOT_TOKEN`**: **MUST be updated.** Get this token from BotFather on Telegram by creating a new bot.
    *   Example: `BOT_TOKEN = "1234567890:ABCdefGhIJKLmnopQRSTuvwxyz123456789"`
*   **`ADMIN_ID`**: **MUST be updated.** This is your personal Telegram User ID. You can get it from bots like `@userinfobot`.
    *   Example: `ADMIN_ID = "123456789"`
*   **`LOG_CHANNEL_ID`**: **MUST be updated.** The ID of a private Telegram channel or group where the bot will send its operational logs. The bot (identified by `BOT_TOKEN`) must be an administrator in this channel/group.
    *   To get a channel/group ID, you can use a bot like `@RawDataBot` or temporarily forward a message from the target chat to `@JsonDumpBot`. For channels, it usually starts with `-100`.
    *   Example: `LOG_CHANNEL_ID = -1001234567890`
*   **`MAX_ACCOUNTS_PER_API`**: (Optional) Maximum number of user accounts to use per API key. Default is `10`. You can adjust this if needed.

### 3.2. `api/api_keys.txt` (CRITICAL)

This file stores the API credentials for your Telegram user accounts (not bot accounts).

*   Format: `api_id:api_hash` (one per line).
*   You can obtain `api_id` and `api_hash` from [my.telegram.org](https://my.telegram.org) by registering an application.
*   Example:
    ```
    1234567:abcdef1234567890abcdef12345678
    7654321:fedcba0987654321fedcba09876543
    ```

### 3.3. `sessions/` Directory (CRITICAL)

This directory will store the session files for your Telegram user accounts.

*   Place your Telethon `.session` files here. Each `.session` file corresponds to a Telegram user account that will be used for inviting.
*   If you don't have these files, they are typically generated the first time a Telethon script successfully logs into a user account. This bot will attempt to authorize the sessions if valid API keys are provided and the accounts are not yet authorized via these session files.
*   The session files should be named (e.g., `my_account1.session`, `user2.session`).

### 3.4. `username/usernames.txt`

This file contains the list of users you want to invite to your target group/channel.

*   Format: One username per line, **without** the `@` symbol.
*   Example:
    ```
    user_one
    anotheruser
    targetperson
    ```
*   **Alternative:** If this file is empty or does not exist, the bot will prompt you in the console to enter a source chat URL (e.g., `https://t.me/public_chat_to_scrape`). The bot will then attempt to scrape users from that chat and populate `usernames.txt`.

### 3.5. `username/used.txt`

This file is automatically generated and managed by the bot.

*   It stores usernames that have already been processed or invited to avoid duplicate attempts.
*   You generally do not need to edit this file manually.

### 3.6. `settings/dest.py` (CRITICAL)

This file specifies the target group or channel where users will be invited.

*   **`dest`**: **MUST be updated.** Set this variable to the username or ID of your target Telegram group/channel.
    *   For a public group/channel: `dest = '@your_target_group'`
    *   For a private group/channel: `dest = -1001234567890` (the chat ID)
    *   Example: `dest = 'https://t.me/myawesometargetgroup'` or `dest = '@myawesometargetgroup'`

### 3.7. `settings/delay.py`

This file controls the delays (in seconds) between various actions performed by the bot.

*   `delay_after_join`: Pause after an account joins the target group.
*   `delay_after_invite`: Pause after an account attempts to invite a user.
*   `delay_after_error`: Pause after an error occurs.
*   `delay_between_accounts`: Pause before switching to the next Telegram account.
*   `delay_between_clients`: General delay between client operations.
*   Default values are provided. You can adjust these if you experience issues like flood waits, but be cautious. Shorter delays increase the risk of account restrictions.

### 3.8. `settings/proxy.txt` (Optional)

If you want to use proxies for your Telegram accounts, configure them in this file.

*   **MTProto Proxy Format**: `mtproto:server:port:secret`
    *   Example: `mtproto:proxy.example.com:443:abcdef1234567890abcdef1234567890`
*   **HTTP/SOCKS5 Proxy Format**:
    *   `type:host:port`
    *   `type:host:port:username:password`
    *   `type` can be `http`, `socks4`, or `socks5`.
    *   Examples:
        ```
        socks5:127.0.0.1:1080
        http:proxy.example.com:8080:user:pass
        ```
*   If this file does not exist or is empty, the bot will run without using proxies. Each account will cycle through the provided proxies.

## 4. Running the Bot

1.  Navigate to the project's root directory in your terminal or command prompt.
2.  Run the bot using the command:
    ```bash
    python main.py
    ```
3.  Monitor the console output for real-time status updates, progress, and any error messages.
4.  Check the Telegram log channel (that you configured in `settings/config.py`) for logs sent by the bot.

## 5. Important Security Notes

*   **Change Default Credentials:** It is **absolutely critical** that you change the default placeholder values in `settings/config.py` (especially `BOT_TOKEN`, `ADMIN_ID`, `LOG_CHANNEL_ID`) and `settings/dest.py` (`dest` variable) before running the bot. Failure to do so can lead to security vulnerabilities or the bot not working as intended.
*   **Log Channel Privacy:** Keep your Telegram log channel private and ensure only authorized individuals (like yourself) have access to it, as it may contain operational details.
*   **Responsible Use:** Use this bot responsibly and in accordance with Telegram's Terms of Service. Automated actions can lead to restrictions on your Telegram accounts if not used carefully. Be mindful of invitation limits and avoid spamming.
*   **Session File Security:** Your `.session` files in the `sessions/` directory contain active login tokens for your Telegram accounts. Protect them as you would passwords. Do not share them.

---

This guide should help you get the bot up and running. If you encounter issues, carefully review your configuration and the bot's log output for clues.
